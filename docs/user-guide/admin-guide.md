# অ্যাডমিন গাইড

ট্রাস্টের ওয়েবসাইট নিজে চালানোর জন্য এই গাইড। টেকনিক্যাল টার্ম ইংরেজিতেই রাখা হয়েছে।

## লগইন

- ঠিকানা: সাইটের `/admin/` — এই লিঙ্ক কোথাও মেনু/লিঙ্কে নেই (unlisted), বুকমার্ক করে রাখুন।
- Email + password দিয়ে লগইন করুন। ভুল পাসওয়ার্ড দিলে "ভুল পাসওয়ার্ড" মেসেজ আসবে; অনেকবার ভুল হলে "অনেকবার চেষ্টা হয়েছে — কয়েক মিনিট পরে আবার"।
- লগইন করলেই সিস্টেম চেক করে আপনি অ্যাডমিন কিনা (`admins` তালিকায় আছেন কিনা)। অ্যাডমিন না হলে সঙ্গে সঙ্গে লগআউট হয়ে যাবেন — এটা ধরে নিন যে অ্যাকাউন্টটা ভুল।
- একবার লগইন করলে ব্রাউজার মনে রাখবে (আবার আবার লগইন করতে হবে না), যতক্ষণ না লগআউট করেন।

### পাসওয়ার্ড ভুলে গেলে

লগইন ফর্মে "পাসওয়ার্ড ভুলে গেছেন?" লিঙ্ক আছে — ইমেল বক্সে আপনার admin ইমেলটা লিখে এই লিঙ্কে ক্লিক করলে সেই ইমেলে একটা রিসেট লিঙ্ক পাঠানো হবে ("রিসেট লিঙ্ক ইমেলে পাঠানো হয়েছে" মেসেজ দেখাবে)। ভুল/অস্তিত্বহীন ইমেল দিলেও একই মেসেজ দেখাবে (ইচ্ছাকৃত — কেউ যাতে ইমেল আন্দাজ করে "এই অ্যাকাউন্ট আছে কিনা" বুঝতে না পারে), তাই ইমেলে কিছু না এলে ঠিকানাটা আরেকবার মিলিয়ে দেখুন বা ডেভেলপারকে জানান।

## ড্যাশবোর্ড

লগইনের পর ১৮টা কার্ড দেখবেন (এই ক্রমেই — `admin/js/admin.js`-এর import order, ঠিক এই ক্রমেই কার্ডগুলো তৈরি হয়):

| কার্ড | কী করে |
|---|---|
| 📢 ঘোষণা | সাইটের প্রতিটা পাতার ওপরে "লাইভ স্ট্রিপ"-এ যা দেখাবে |
| ⚙️ সেটিংস | ট্রাস্টের নাম, ঠিকানা, ফোন/WhatsApp/ইমেল, রেজিস্ট্রেশন নম্বর, UPI, পুজোর তারিখ-সময়, থিম, কোন সেকশন দেখা যাবে, Maintenance mode, সোশ্যাল লিঙ্ক, প্রতিষ্ঠার বছর, দানের খাত, credibility items, meta description |
| 🎨 ডিজাইন | সাইটের রূপ — পাঁচটার একটা বাছুন (প্রিভিউ → চালু করুন); রং/ফন্ট নিজে বদলানো; হোমপেজের সেকশন ক্রম/on-off; সেটিংস-এ "এই বছরের থিম" আলাদা জিনিস |
| ✏️ লেখা | সাইটের প্রতিটা লেখা (মেনু, বোতাম, শিরোনাম, হিন্ট) নিজের ভাষায় বদলানো |
| 🖼️ UI ছবি | হিরো/ব্র্যান্ড মার্ক/favicon/OG ছবি ইত্যাদি নির্দিষ্ট জায়গার ছবি বদলানো |
| 🏺 সংস্কৃতি | হোমপেজের কারুশিল্প-পরিচিতি কার্ড (মুখা/ঢোকরা/আত্রেয়ী…) |
| 📄 পাতা | প্রাইভেসি/টার্মস, রিফান্ড নীতি, ট্রাস্ট পরিচিতি, যোগাযোগ, FAQ, খবর, ডাউনলোড, ৪০৪ — সাইটের ৮টা স্ট্যাটিক পাতার লেখা |
| 📜 লগ | কে কী বদলেছে (অডিট) আর ক্লায়েন্ট এরর রিপোর্ট — দুটো আলাদা ট্যাব |
| 📜 ইতিহাস | ট্রাস্টের ইতিহাস — বছর ধরে ধরে এন্ট্রি |
| 👥 কমিটি | কমিটির সদস্যদের নাম/পদ/ছবি |
| 🖼️ গ্যালারি | ফটো অ্যালবাম |
| 📅 অনুষ্ঠান | ইভেন্ট/অনুষ্ঠানের তালিকা |
| 📤 ব্যাকআপ | সব ডেটা JSON ডাউনলোড |
| 💰 দান | দাতাদের তালিকা (রসিদ নং, মাধ্যম) আর "দাতাদের তালিকা" (donor wall)-এ কে দেখাবে |
| 📊 হিসাব | বছর-ভিত্তিক আয়-ব্যয়ের হিসাব, অডিট PDF |
| 🧾 সদস্য | কমিটির সদস্যদের ফোন নম্বর দিয়ে লগইন — প্রতিশ্রুতি/পেমেন্ট |
| 📋 নোটিশ | শুধু সক্রিয় সদস্যদের জন্য নোটিশ (`/members.html`-এ ফোন OTP দিয়ে লগইন করলে দেখা যায়) |
| 🗓️ দায়িত্ব তালিকা | কোন সদস্যর কবে কী ডিউটি — শুধু তালিকাভুক্ত সদস্যরাই নিজের সারি দেখতে পান |

নোট: 📜 আইকনটা ইতিহাস আর লগ দুটো কার্ডেই ব্যবহার হয়েছে (কোডেই তাই লেখা) — নাম দেখেই দুটো আলাদা করা যায়।

প্রতিটা কার্ডের পাশে (আর প্রতিটা পাতার ওপরে) একটা **"?"** বোতাম আছে — চাপলে ঠিক এই গাইডের সেই কার্ডের অংশে নিয়ে যাবে (নতুন ট্যাবে, GitHub-এ)। ড্যাশবোর্ডে থাকা অবস্থায় "?" চাপলে এই গাইডের একদম ওপরে (ড্যাশবোর্ড অংশে) নিয়ে যাবে।

ওপরে ডানদিকে ভাষা বোতাম (বাং/EN) দিয়ে অ্যাডমিন প্যানেলের ভাষা বদলাতে পারবেন — এটা শুধু প্যানেলের UI-এর ভাষা, কনটেন্টের bn/en আলাদা।

<a id="announcements"></a>
## 📢 ঘোষণা (Announcements)

- সাইটের প্রতিটা পাতার একদম ওপরে "লাইভ স্ট্রিপ"-এ ঘোষণাগুলো রিয়েল-টাইমে দেখা যায় (শুধু হোমপেজে না) — visitor পেজ রিলোড না করলেও নতুন ঘোষণা সাথে সাথে দেখা যাবে।
- ফর্মে: বার্তা (bn+en), "পিন করুন" (checkbox — টিক দিলে এটাই সবসময় সবার আগে থাকবে, তারিখ যাই হোক), "এখন লাইভ" (টিক দিলে লাল 🔴 ব্যাজ দেখাবে), মেয়াদ শেষ (ঐচ্ছিক — সময় পেরোলে নিজে থেকেই আর দেখাবে না)।
- "পাবলিশ" বোতামে নতুন ঘোষণা সাথে সাথে সাইটে চলে যায় — এখানে আলাদা draft ধাপ নেই। পরে চাইলে "আনপাবলিশ" করে লুকাতে পারবেন।
- একসাথে বেশি ঘোষণা থাকলে সাইট সর্বোচ্চ ৫টা দেখায় (পিন করা এগুলো সবসময় ওপরে)।

<a id="design"></a>
## ডিজাইন বদলানো

🎨 ডিজাইন কার্ডে সাইটের পাঁচটা রূপ (theme) দেখবেন, প্রতিটার নিচে রঙের নমুনা (swatch):

| থিম | কেমন |
|---|---|
| সিদ্ধি | গণেশের নিজের রং — সিঁদুর, পীতাম্বর, দূর্বা, সোনালি |
| মুখা | কুশমণ্ডির কাঠের মুখোশ — হলুদ, লাল, কালো |
| ঢোকরা | পিতলের আলো — গাঢ় bronze, সোনালি রেখা |
| আত্রেয়ী | নদী ও ধান — শান্ত, হিসাব সামনে |
| বাণগড় | পোড়ামাটির ঐতিহ্য — ইটের লাল, sandstone |

- **প্রিভিউ** বোতাম নতুন ট্যাবে পাবলিক সাইট খোলে সেই থিম লাগিয়ে (`?theme=...`) — এটা শুধু আপনার ওই ট্যাবেই দেখা যায়, অন্য কেউ দেখবে না, সাইটে কিছু সেভও হয় না।
- **চালু করুন** বোতাম চাপলে পাসওয়ার্ড আবার চাইবে (re-authentication), তারপর পুরো সাইটে এই থিমটাই সবার জন্য প্রয়োগ হয়ে যায় — visitor-রা পরের পেজ-লোডেই নতুন রূপ দেখবেন।
- সেটিংস কার্ডের "এই বছরের থিম" এটা থেকে সম্পূর্ণ আলাদা জিনিস — সেটা হোমপেজে দেখানো এই বছরের পুজোর নাম/বিষয় (যেমন "সবুজায়ন"), রঙের থিম না।
- admin panel-ও বাছা theme-এ দেখায় — সাইট আর অ্যাডমিন প্যানেল সবসময় একই রূপে থাকে।
- **রং**: থিম বাছার নিচে প্রতিটা রঙের সারি — রং picker + hex কোড + তার পটভূমির বিপরীতে contrast অনুপাত (✓/⚠, শুধু পরামর্শ, সেভ আটকায় না)। খালি রাখলে থিমের নিজের রং থাকে; "থিমের রং-এ ফেরাও" দিয়ে একলাফে সব ফেরানো যায়।
- **ফন্ট**: শিরোনাম আর লেখার ফন্ট আলাদা আলাদা বাছা যায় — সাইটে আগে থেকে লোড হওয়া চারটা ফন্টের মধ্যে থেকেই (নতুন ফন্ট যোগ করা যায় না)।
- **হোম-এর section**: হোমপেজে কোন অংশ (হিরো, বিশ্বাসযোগ্যতা strip, এক নজরে, থিম story, সংস্কৃতি card, গ্যালারি, সূচি, হিসাব, দান band, কমিটি, সদস্য) দেখাবে/লুকাবে (checkbox) আর কোন ক্রমে দেখাবে (↑ ↓)।
- এই তিনটেই default থাকে (আজ যা লাইভ আছে ঠিক তাই); বদলালে override হয়ে যায়, প্রতিটার নিজের "…-এ ফেরাও" বোতাম দিয়ে আবার default-এ ফেরানো যায়।

<a id="strings"></a>
## ✏️ লেখা (Strings)

- সাইটের প্রায় প্রতিটা লেখা — মেনু, বোতাম, পাতার শিরোনাম/লিড, ফুটার, হিন্ট, মেসেজ — এখান থেকে bn+en দুই ভাষাতেই বদলানো যায়। ইনপুট বক্সে হালকা ধূসর করে ডিফল্ট লেখাটা placeholder হিসেবে দেখা যায়, যাতে বোঝা যায় খালি রাখলে কী দেখাবে।
- ওপরে খুঁজুন বক্সে key বা লেখা দিয়ে সার্চ করা যায় — মিলে যাওয়া গ্রুপগুলো নিজে থেকে খুলে যাবে।
- একটা সারির পাশে "default-এ ফেরাও" চাপলে শুধু সেই সারিটাই খালি হয়ে যাবে (ডিফল্টে ফিরবে); নিচে একটাই "সেভ করুন" বোতাম আছে যেটা শুধু বদলানো সারিগুলোই লেখে।
- **সাবধানতা**: অ্যাডমিন প্যানেলের নিজের কোনো লেবেল (যেমন কোনো পাতার শিরোনাম) বদলে সেভ করলে, সেই বদল রিলোড/রিলগইনের পরে দেখা যাবে — খোলা ট্যাবে সাথে সাথে না।
- default থাকে, বদলালে override হয়, "default-এ ফেরাও" দিয়ে ফেরানো যায়।

<a id="media"></a>
## 🖼️ UI ছবি (Media)

- নির্দিষ্ট কিছু জায়গার ছবি — হিরো (idol/ব্যানার), ব্র্যান্ড মার্ক, favicon, শেয়ার (OG) ছবি, পাতাভিত্তিক হেডার ব্যাকগ্রাউন্ড, দান-ব্যান্ড ছবি, সদস্য-অংশের ছবি — একটা তালিকা হিসেবে দেখা যায়, প্রতিটার সাথে থাম্বনেইল (বা "আঁকা art দেখাচ্ছে")।
- **Choose File** দিয়ে আপলোড করলে ছবি resize + upload হয়ে সেই স্লটে বসে; **সরাও** চাপলে আবার আঁকা art-এ ফিরে যায়।
- খালি স্লট মানেই খারাপ কিছু না — "নথিং স্ট্যাটিক" মানে সাইট খালি দেখাবে না, আঁকা art-ই ডিফল্ট।
- default থাকে (আঁকা art), বদলালে override হয় (আপলোড করা ছবি), "সরাও" দিয়ে আবার default-এ ফেরানো যায়।

<a id="culture"></a>
## 🏺 সংস্কৃতি (Culture)

- হোমপেজের "আমাদের মাটি, আমাদের শিল্প" অংশের কার্ডগুলো (মুখা/ঢোকরা/আত্রেয়ী ধরনের কারুশিল্প-পরিচিতি) — কমিটির মতোই তালিকা/এডিট/reorder, ছবি আপলোড, পাবলিশ টগল।
- নতুন কার্ড + নতুন এন্ট্রি ডিফল্টে ড্রাফট থাকে যতক্ষণ না পাবলিশ করছেন (Draft বনাম Publish অংশ দেখুন)।
- default থাকে (কোডে থাকা তিনটে ডিফল্ট কার্ড, production-এ সিড করা), বদলালে/মুছলে override হয়ে যায় — এই তিনটে অবশ্য অন্য সবকিছুর মতো "ফেরাও" বোতাম দিয়ে ফেরানো যায় না (এটা একটা collection, single override doc না), তাই এডিট করার আগে ভেবে করুন।

<a id="pages"></a>
## 📄 পাতা (Pages)

- সাইটের ৮টা স্ট্যাটিক পাতা এখান থেকেই লেখা হয়: প্রাইভেসি পলিসি + টার্মস (`privacy.html`), রিফান্ড/দান-ফেরত নীতি (`privacy.html#refund`), ট্রাস্ট পরিচিতি — উদ্দেশ্য/ট্রাস্টি/দান কোথায় যায় (`trust.html`), যোগাযোগ (`contact.html`), FAQ (`faq.html`), খবর/ঘোষণার আর্কাইভ (`news.html`), ডাউনলোড (`downloads.html`), আর "পাতা পাওয়া যায়নি" ৪০৪ পাতা (`404.html`)।
- কার্ডে ঢুকলে এই ৮টার একটা তালিকা দেখবেন — একটাতে ক্লিক করলে তার bn/en শিরোনাম আর বডি (rich text, একাধিক প্যারাগ্রাফ) এডিট করার ফর্ম খুলবে।
- প্রতিটার নিজের **প্রিভিউ** বোতাম আছে — নতুন ট্যাবে ড্রাফট অবস্থাতেও (আপনি লগইন থাকলে) আসল পাতাটা খুলে দেখায়।
- এই ৮টা পাতার id বদলানো/নতুন পাতা তৈরি করা/মোছা যায় না — এগুলো সিস্টেম পাতা, তালিকাভুক্ত কনটেন্টের (ইতিহাস/অনুষ্ঠানের) মতো না। প্রতিটার কোডে একটা ডিফল্ট বাংলা+ইংরেজি লেখা আছে (`js/page-defaults.js`), তাই এডিট না করলেও পাতা খালি দেখাবে না।

<a id="log"></a>
## 📜 লগ (Log)

- এখানে দুটো ট্যাব:
  - **অডিট** — অ্যাডমিন প্যানেলে কে (কোন uid), কখন, কোন কালেকশনে, কী কাজ (তৈরি/পরিবর্তন/মোছা/পুনরুদ্ধার/ক্রম পরিবর্তন/প্রকাশ/অপ্রকাশ/রপ্তানি) করেছেন তার তালিকা (সাম্প্রতিক ২০০টা), কালেকশন দিয়ে ফিল্টার করা যায়, প্রতিটা সারির "বিস্তারিত" খুললে আগে/পরের ডেটা (JSON) দেখা যায়।
  - **ত্রুটি** — সাইটে ভিজিটরের ব্রাউজারে যে জাভাস্ক্রিপ্ট এরর ধরা পড়েছে তার রিপোর্ট (সাম্প্রতিক ১০০টা): বার্তা, কোন পাতায়, আর stack trace। এই ট্যাবে প্রথমবার ক্লিক করলেই লোড হয় (আগে থেকে না)।
- দুটোই শুধু অ্যাডমিন পড়তে পারেন, কেউ বদলাতে/মুছতে পারে না — এটা একটা স্থায়ী, পরিবর্তনহীন রেকর্ড।

<a id="history"></a>
## 📜 ইতিহাস (History)

- ট্রাস্টের ইতিহাস — বছর ধরে ধরে এন্ট্রি (বছর + শিরোনাম + বডি), `about.html`-এ টাইমলাইন হিসেবে দেখায়।
- তালিকা/এডিট/reorder/ড্রাফট-পাবলিশ/প্রিভিউ — সবই ওপরের সাধারণ নিয়মে ("Draft বনাম Publish", "Preview", "ক্রম বদলানো" অংশ দেখুন)।

<a id="committee"></a>
## 👥 কমিটি (Committee)

- কমিটির সদস্যদের নাম/পদ/ছবি — তালিকা/এডিট/reorder সাধারণ নিয়মে।
- **"পদাধিকারী (সামনে দেখাও)"** টিক দিলে সেই সদস্য কমিটি পেজে সবার আগে বড় করে (officer ring card) দেখাবে — সভাপতি/সম্পাদক/কোষাধ্যক্ষদের জন্য এটা ব্যবহার করুন।
- এখানে publish বোতাম নেই — "ওয়েবসাইটে দেখাও" checkbox দিয়ে পাবলিক/ড্রাফট ঠিক হয় (Draft বনাম Publish অংশ দেখুন)।
- তালিকার ওপরে একটা সার্চ বক্স আছে — নাম/পদ দিয়ে খুঁজলে তালিকা সাথে সাথে ফিল্টার হয়ে যায় (নতুন কোনো ডেটা লোড হয় না, যা আছে তার মধ্যেই খোঁজে)।

<a id="albums"></a>
## 🖼️ গ্যালারি (Albums)

- ফটো অ্যালবাম — প্রতিটা অ্যালবামের নাম/বছর, ভেতরে একাধিক ছবি (ছবি আপলোডের টিপস অংশ দেখুন — multi-select, automatic resize)।
- **"সেরা মুহূর্ত strip-এ দেখাও"** টিক দিলে সেই অ্যালবামের কভার ছবি হোমপেজের "সেরা মুহূর্ত" strip-এ দেখাবে — কয়েকটা ভালো অ্যালবাম বাছুন, সবগুলোতে টিক দেবেন না।
- প্রতিটা ছবির একটা ঐচ্ছিক `alt` টেক্সট ফিল্ড আছে (ক্যাপশন থেকে আলাদা) — স্ক্রিন-রিডার/সার্চ ইঞ্জিনের জন্য; খালি রাখলে ক্যাপশন, তাও না থাকলে অ্যালবামের নাম ব্যবহার হয়।
- প্রতিটা অ্যালবামের নিজের প্রিভিউ বোতাম আছে (`gallery.html?album=…&preview=1`) — ড্রাফট অবস্থাতেও দেখা যায়।

<a id="events"></a>
## 📅 অনুষ্ঠান (Events)

- ইভেন্ট/অনুষ্ঠানের তালিকা — নাম, ভেন্যু, বিবরণ, শুরু/শেষ সময়, তালিকা/এডিট/reorder/ড্রাফট-পাবলিশ/প্রিভিউ সাধারণ নিয়মে।
- পাবলিশড ইভেন্টের পাবলিক পেজে (`events.html`) একটা "ক্যালেন্ডারে যোগ করুন" (`.ics` ডাউনলোড) বোতামও থাকে — এটা অ্যাডমিন থেকে আলাদা কিছু সেট করতে হয় না, ইভেন্টের ডেটা থেকেই তৈরি হয়।

<a id="donations"></a>
## 💰 দান (Donations)

- প্রতিটা দানের এন্ট্রি: দাতার নাম, পরিমাণ, তারিখ, মাধ্যম (নগদ/UPI/ব্যাঙ্ক), রসিদ নং, নোট।
- **দাতার ফোন নম্বর কখনো এখানে রাখবেন না** — সাইটের ডেটাবেসে দাতাদের ফোন নম্বর সংরক্ষণ করা হয় না, এটা ইচ্ছাকৃত।
- "নাম প্রকাশে অনিচ্ছুক" টিক দিলে পাবলিক দেয়ালে নাম না দেখিয়ে "নাম প্রকাশে অনিচ্ছুক" লেখা দেখাবে।
- "দেয়ালে দেখান" টিক না থাকলে সেই দান পাবলিক /donate.html পেজে একদম দেখা যাবে না (রসিদের জন্য এন্ট্রি রাখতে চাইলে এটা off রাখুন)।
- বছর অনুযায়ী ফিল্টার করে মোট/মাধ্যম-ভিত্তিক যোগফল দেখা যায়।
- তালিকার ওপরে সার্চ বক্স — দাতার নাম/রসিদ নং দিয়ে খুঁজলে ফিল্টার হয়ে যায়।

<a id="transparency"></a>
## 📊 হিসাব (Transparency)

- প্রতিটা বছরের জন্য আলাদা এন্ট্রি: আয়ের সারি (খাত + পরিমাণ) আর ব্যয়ের সারি — যোগফল আর ব্যালেন্স নিজে থেকেই হিসাব হয়ে দেখাবে।
- অডিট রিপোর্ট/নথি হিসেবে PDF (৫ MB পর্যন্ত) আপলোড করা যায়, শিরোনাম সহ।
- "পাবলিশড" না করা পর্যন্ত /transparency.html পেজে সাধারণ visitor-রা দেখতে পাবে না — কিন্তু আপনি লগইন থাকা অবস্থায় `?preview=1&year=২০২৪` (উদাহরণ) দিয়ে ড্রাফট বছরটাও দেখে নিতে পারবেন, অথবা নিজের এন্ট্রির প্রিভিউ বোতাম চাপুন।

<a id="members"></a>
## 🧾 সদস্য (Members)

- এখানে কমিটির সদস্যদের তালিকা — ফোন নম্বর (E.164, যেমন +919999999999) দিয়ে সনাক্ত হয়, তাই একটা ফোন নম্বর একবারই যোগ করা যাবে।
- প্রতিটা সদস্যর: নাম, পদ, প্রতিশ্রুতি (pledge) টাকা, আর পেমেন্টের তালিকা (তারিখ + পরিমাণ + নোট) — বাকি (due) হিসাব নিজে থেকেই বেরোয়।
- "সক্রিয়" টিক তুলে দিলে (বা এন্ট্রি মুছে দিলে) সেই সদস্য /members.html-এ ফোন দিয়ে লগইন করলেও নিজের নোটিশ/দায়িত্ব তালিকা আর দেখতে পাবেন না — শুধু নিজের প্রতিশ্রুতি/পেমেন্ট দেখতে পারবেন।
- সদস্যরা /members.html-এ নিজের ফোন নম্বর দিয়ে OTP-ভিত্তিক লগইন করেন (ইমেল-পাসওয়ার্ড না) — এটা অ্যাডমিন লগইন থেকে সম্পূর্ণ আলাদা ব্যবস্থা।
- তালিকার ওপরে সার্চ বক্স — নাম/ফোন নম্বর দিয়ে খুঁজলে ফিল্টার হয়ে যায়।

<a id="notices"></a>
## নোটিশ (Notices)

- 🧾 সদস্যর মতোই bn+en টাইটেল/বডি (HTML: `<p> <b> <ul> <li>` চলবে) আর পাবলিশ/ড্রাফট।
- শুধু **সক্রিয় সদস্যরাই** /members.html-এ লগইন করে নোটিশ দেখতে পান — সাধারণ visitor বা নিষ্ক্রিয় সদস্য দেখতে পান না।

<a id="roster"></a>
## দায়িত্ব তালিকা (Roster)

- তারিখ + দায়িত্ব (bn+en) + কোন কোন সদস্য (ফোন নম্বর বেছে) — একই দিনে একাধিক সদস্য/একাধিক দায়িত্ব থাকতে পারে।
- প্রতিটা সদস্য /members.html-এ লগইন করলে শুধু **নিজের নাম যেখানে আছে** সেই সারিগুলোই দেখেন, পুরো তালিকা নয়।

## নতুন কিছু ফিল্ড (Phase 5)

- **👥 কমিটি → "পদাধিকারী (সামনে দেখাও)"**: টিক দিলে সেই সদস্য কমিটি পেজে সবার আগে বড় করে (officer ring card) দেখাবে — সভাপতি/সম্পাদক/কোষাধ্যক্ষদের জন্য এটা ব্যবহার করুন। বাকি সদস্যরা তার নিচে সাধারণ তালিকায় থাকবেন।
- **🖼️ গ্যালারি → অ্যালবাম ফর্মে "সেরা মুহূর্ত strip-এ দেখাও"**: টিক দিলে সেই অ্যালবামের কভার ছবি হোমপেজের "সেরা মুহূর্ত" strip-এ দেখাবে। কয়েকটা ভালো অ্যালবাম বাছুন, সবগুলোতে টিক দেবেন না।
- **⚙️ সেটিংস → "দানের খাত"**: একটা টেক্সট বক্স, প্রতি লাইনে একটা খাত — ফরম্যাট `বাংলা নাম | English name | সাজেস্টেড টাকার অঙ্ক` (যেমন `প্রতিমা | Idol | 501,1101`)। এখান থেকেই /donate.html পেজে "কোন খাতে" কার্ডগুলো আর তার নিচের টাকার চিপ (chip) বোতামগুলো তৈরি হয়।
- **⚙️ সেটিংস → "দেখাও: culture"**: অন্য সেকশন visibility চেকবক্সগুলোর মতোই — টিক তুললে হোমপেজের "আমাদের মাটি, আমাদের শিল্প" (মুখা/ঢোকরা/আত্রেয়ী কারুশিল্পের পরিচিতি) অংশটা লুকিয়ে যাবে।

## bn + en — দুটো ফিল্ড

নাম, শিরোনাম, বিবরণের মতো প্রায় প্রতিটা টেক্সট ফিল্ডে দুটো বক্স থাকে — একটা `BN` (বাংলা), একটা `EN` (ইংরেজি)। দুটোই ভরুন; ওয়েবসাইটে দর্শক যে ভাষা বেছে নেবে সেটাই দেখাবে। একটা খালি রাখলে সেই ভাষায় খালি দেখাবে।

## Draft বনাম Publish

- **ইতিহাস, গ্যালারি (অ্যালবাম), অনুষ্ঠান** — এগুলোতে দুটো বোতাম: "ড্রাফট সেভ" (শুধু সেভ হবে, ওয়েবসাইটে দেখাবে না) আর "পাবলিশ" (সেভ + সাথে সাথে ওয়েবসাইটে দেখাবে)। তালিকায় প্রতিটার পাশে "ড্রাফট" বা "পাবলিশড" ব্যাজ দেখবেন।
- **কমিটি** — এখানে publish বোতাম নেই; বরং একটা checkbox "ওয়েবসাইটে দেখাও" — টিক থাকলে পাবলিক, না থাকলে ড্রাফট।
- নতুন এন্ট্রি ডিফল্টে ড্রাফট থাকে যতক্ষণ না পাবলিশ করছেন।

## Preview

- যে কার্ড একটা নির্দিষ্ট পাবলিক পেজের কনটেন্ট এডিট করে (ঘোষণা, পাতা, ইতিহাস, কমিটি, গ্যালারি, অনুষ্ঠান, হিসাব), তার এন্ট্রিতে (নতুন না হলে) একটা "প্রিভিউ" বোতাম আছে — এটা নতুন ট্যাবে আসল পাবলিক পেজ `?preview=1` দিয়ে খোলে, ড্রাফট/আনপাবলিশড অবস্থাতেও দেখা যায় (আপনি লগইন করা অবস্থায় থাকলেই)। এটা সাধারণ visitor-রা দেখতে পাবে না।
- যে কার্ড পুরো সাইটে প্রযোজ্য (ডিজাইন, সেটিংস, লেখা, UI ছবি, ব্যাকআপ), তার প্রিভিউ বোতাম হোমপেজ খোলে — কারণ ওই বদলগুলো কোনো একটা পাতার না, সারা সাইটের।

## ছবি আপলোডের টিপস

- **কমিটি ছবি**: পোর্ট্রেট (লম্বালম্বি) ছবি ভালো দেখায়, প্রায় ৬০০px চওড়া যথেষ্ট। একটাই ছবি বাছুন।
- **অ্যালবাম ছবি**: ল্যান্ডস্কেপ (আড়াআড়ি) ছবি ভালো দেখায়। ফোনের গ্যালারি থেকে একসাথে অনেকগুলো ছবি বাছতে পারবেন (multi-select)।
- প্রথম যে ছবিটা আপলোড করবেন, সেটাই স্বয়ংক্রিয়ভাবে অ্যালবামের কভার ছবি হয়ে যায় (পরে "কভার ছবি" ফিল্ড দিয়ে বদলাতে পারেন)।
- **আপলোডের সময় পেজ বন্ধ করবেন না বা অন্য ট্যাবে যাবেন না** — ছবি resize + upload হতে একটু সময় লাগে, progress bar দেখে অপেক্ষা করুন।
- আপলোডের সময় ছবি automatic resize হয়ে যায় (ছোট হয়ে), তাই বড় ছবি নিশ্চিন্তে দিতে পারেন।

## ক্রম বদলানো (Reorder)

তালিকার প্রতিটা আইটেমের পাশে ↑ ↓ বোতাম আছে — চাপলে ওই আইটেম ওপরে/নিচে সরে যাবে (ওয়েবসাইটে যে ক্রমে দেখাবে, সেটাই বদলায়)। অ্যালবামের ভেতরের ছবিগুলোও নিজেদের ↑ ↓ দিয়ে সাজানো যায়।

## মোছা (Delete) = Soft delete

"মুছুন" বোতাম চাপলে ডেটা আসলে পুরোপুরি মোছে না — শুধু "deleted" চিহ্নিত হয় আর ওয়েবসাইট থেকে হাইড হয়ে যায়। মোছার আগে দুটো নিরাপত্তা ধাপ:
1. একটা কনফার্ম মেসেজ ("সত্যিই মুছবেন?")
2. আপনার পাসওয়ার্ড আবার চাওয়া হবে (re-authentication) — এটা যাতে ভুলে বা অন্য কেউ লগইন খোলা রেখে গেলে মুছে না ফেলতে পারে।

সেটিংস সেভ করার সময়ও পাসওয়ার্ড আবার চাওয়া হবে — এটা স্বাভাবিক, প্রতিবার হবে।

### পুনরুদ্ধার (Restore) — নিজেই ফিরিয়ে আনুন

তালিকাওয়ালা প্রতিটা কার্ডে (ইতিহাস, কমিটি, গ্যালারি, অনুষ্ঠান, দান, সদস্য, নোটিশ, দায়িত্ব তালিকা, সংস্কৃতি) একটা "মুছে ফেলা দেখাও" checkbox আছে — টিক দিলে তালিকাটা উল্টে যায়: শুধু মোছা এন্ট্রিগুলো দেখাবে, আর প্রতিটার পাশে এডিট/reorder বোতামের বদলে একটা **"পুনরুদ্ধার"** বোতাম থাকবে। চাপলেই এন্ট্রিটা সাথে সাথে ফিরে এসে আগের জায়গায় পাবলিক/ড্রাফট অবস্থায় ফিরে যায় — ডেভেলপারকে জানানোর দরকার নেই, ভুল করে মুছে ফেললে নিজেই ঠিক করে নিতে পারবেন। প্রতিটা মোছা/পুনরুদ্ধার 📜 লগ কার্ডে রেকর্ড থাকে।

## সেটিংসে যা যা বদলাতে পারবেন

- **সেকশন visibility**: about/committee/gallery/events ইত্যাদি সেকশন সাইটের মেনু থেকে দেখানো/লুকানো যায়, checkbox দিয়ে।
- **Maintenance mode**: টিক দিলে পুরো পাবলিক সাইট বন্ধ হয়ে "সাইট রক্ষণাবেক্ষণ চলছে"-জাতীয় মেসেজ দেখাবে — কিন্তু অ্যাডমিন প্যানেল স্বাভাবিক চলবে, আপনি লগইন করে কাজ চালিয়ে যেতে পারবেন। কাজ শেষ হলে অবশ্যই আবার আনটিক করুন।
- **পুজোর তারিখ-সময়**: হোমপেজের কাউন্টডাউনে ব্যবহার হয়।
- **সোশ্যাল লিঙ্ক**: Facebook/YouTube/Instagram/WhatsApp গ্রুপ URL — ফুটারে টেক্সট লিঙ্ক হিসেবে দেখাবে (আইকন না, নামটাই লেখা থাকে)। খালি রাখলে সেই লিঙ্কটা দেখাবে না। শুধু `https://` দিয়ে শুরু URL গ্রহণ করবে, নাহলে খালিই থেকে যাবে।
- **প্রতিষ্ঠার বছর**: হোমপেজের বিশ্বাসযোগ্যতা strip-এ "প্রতিষ্ঠিত ⟨বছর⟩" হিসেবে দেখায় (যেমন "প্রতিষ্ঠিত ২০১০") — এখান থেকে কত বছর হয়ে গেছে সেই হিসাব (বয়স) নিজে থেকে বার করা হয় না, শুধু বছরটাই দেখায়।
- **দানের খাত (credibility items)**: একটা টেক্সট বক্স, প্রতি লাইনে একটা আইটেম, ফরম্যাট `বাংলা | English` — হোমপেজের বিশ্বাসযোগ্যতা strip-এ নিজের মতো আইটেম বসাতে পারবেন (উপরে "নতুন কিছু ফিল্ড" অংশের "দানের খাত" ফিল্ড থেকে আলাদা জিনিস, এটা donate পেজের খাত না)।
- **Meta description**: bn/en — সার্চ ইঞ্জিনে/লিঙ্ক শেয়ার করলে যে ছোট বিবরণ দেখা যায়, তার জন্য।
- এই সবক'টা ফিল্ড default থাকে (আজ যা লাইভ আছে/কিছু না থাকলে ফাঁকা), বদলালে override হয়ে যায়; খালি করে সেভ করলেই আবার default-এ ফেরে।

## ব্যাকআপ

📤 কার্ড → JSON ⬇ — মাসে একবার নামিয়ে Google Drive-এ রাখুন। Timestamp গুলো `{seconds, nanoseconds}` আকারে থাকে। এই এক্সপোর্টে সাইটের প্রতিটা কালেকশন থাকে (অডিট লগ আর error রিপোর্ট সহ), তাই একটা ফাইলই পুরো ব্যাকআপ।

## ভুল হলে

কোনো এন্ট্রি ভুল সেভ হয়ে গেলে বা কিছু গোলমাল মনে হলে ডেভেলপারকে জানান — পুরনো ডেটা সাথে সাথে মুছে যায় না (soft delete-এর জন্য), তাই বেশিরভাগ ভুল ঠিক করা যায়। তাড়াহুড়ো করে বারবার সেভ/ডিলিট করবেন না।

## যা করবেন না

- **পাসওয়ার্ড কারো সাথে শেয়ার করবেন না** — একটাই অ্যাডমিন অ্যাকাউন্ট আছে, শেয়ার করলে কে কী করল বোঝা যাবে না।
- **Firestore console-এ গিয়ে সরাসরি ডেটা এডিট করবেন না** — অ্যাডমিন প্যানেল দিয়েই সব বদলান; console থেকে বদলালে audit log-এ থাকবে না আর ভুল ফরম্যাটে ডেটা সেভ হয়ে সাইট ভেঙে যেতে পারে।
- **একই সময়ে দুটো ট্যাব/ডিভাইসে একই এন্ট্রি এডিট করবেন না** — যেটা শেষে সেভ হবে সেটাই থাকবে, আগেরটা হারিয়ে যাবে।
