# Full-site design concept (2026-09-10)

`full-site-concept.html` is the single-file, dependency-free presentation of the
whole public site — home + ইতিহাস · কমিটি · গ্যালারি · অনুষ্ঠান · দান · হিসাব · সদস্য —
in the direction chosen by the owner ("take it as one"): Ganesh's own colours
(sindoor, pitambar, durva, modak, gold) + Dakshin Dinajpur culture (Kushmandi
mukha, Dhokra, Atreyee, Bangarh) + 2026 UI (expressive Bengali type, bento at a
glance, restrained motion).

Open it in a browser; the nav switches pages (hash router). The bottom-right
switcher previews the five theme token sets (সিদ্ধি default · মুখা · ঢোকরা ·
আত্রেয়ী · বাণগড়) — in production this becomes the admin 🎨 ডিজাইন card.

All art is drawn in-file (SVG Ganesh line-art, canvas scenes/garland/mandala);
real photos and the logo PNG replace the canvas scenes during Phase 5.
